This is an application that allows you to track all financial transactions for a 
business or for personal use. 
It allows you to input deposits and payments. While also giving you to the oppotunity to view the
ledger as a whole. Even providing the option to inspect transactions from the previous
year. The menu and submenus are easy to navigate and straight forward.

How to run the application: 

1.Open the project in your preferred Java IDE

2.Run the program from the Main class

3.Follow the menu options to:
- Add transactions
- View the ledger
- Generate reports
